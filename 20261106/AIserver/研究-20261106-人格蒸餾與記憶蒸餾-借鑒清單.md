# 人格蒸餾與記憶蒸餾：借鑒清單（不重構，只補兩個步驟）

日期：2026-11-06
來源：`persona-distill`（pd）與 `@tuhengyu/dsh-full-life-memory`（flm），已拉源碼到 `.dsh_scratch/research/`
原則：我們架構比他們完整（Hindsight 記憶頁、反思、思考線、工作臺、T6、trace），**不搬他們的宿主鉤子**；只借「蒸餾這一步」的**步驟、資料形狀、限制、提示詞**。

## 一、persona-distill 到底蒸餾什麼（步驟／資料／限制／提示詞）

### 1.1 它需要什麼資料

| 檔案 | 是什麼 | 對我們的意思 |
|---|---|---|
| `voice.md` | 人類怎麼說話：原句＋好在哪（樣本，不是規則） | 我們有：主人怎麼說話（session_log 的 user 行、他的原話） |
| `notes.md` | 想明白的結論（帶條件，能少踩一次坑） | 我們有：反思沉澱、bug 教訓、工作臺做完的事 |
| `digest/<月>.md` | 看過什麼（一行一條流水帳，用來補判斷） | 我們有：每日構建、事件日誌、對話紀錄 |
| `out/<日期>.md` | 我自己實際說出去的話（給反面對照用） | 我們有：session_log 的 assistant 行、trace 06_chat_agent |

### 1.2 它的步驟（每天→每週）

1. **每天：找新增**。不記行號、記 sha256；哈希沒變就跳過；變了全量重讀（防「中段插入／刪行」漏掉新樣本）。
2. **每天：抽候選**，四類（一條一行、帶源 id＋位置）：
   - `[說] 名稱｜「原句」｜好在：… · 源/voice:行`（必須是原句，不能自己編）
   - `[判] 結論｜條件 · 源/notes:行`
   - `[活] 人怎麼活的一句話｜現場例子 · 源/digest:行`（必須來自互動：誰被無視、誰道歉、誰接住話）
   - `[反] 我的毛病｜我的原句：「…」｜人類對照：「…」｜改：一句能照做的 · self/日期`（必須能舉出自己真的說過的原句）
3. **每天：反面對照**（`[反]`）：取自己說過的 20 句 → 比六個維度（結構／收口／標點／示弱／裝飾／體量）→ 一天最多 3 條。
4. **每週：定型**（三個條件同時：距上次 ≥7 天、`[說]`≥3、所有源都讀得出來；或候選 ≥40 條）。步驟：
   - 備份舊人格 → 讀「全部候選＋所有源原料」→ **重寫固定五段**：原則（≤20 行）／場景樣本（≤150 行）／我怎么活（≤40 行）／判斷（≤30 行）／我該少說（≤10 行）。
   - **淘汰不是累加**：總量 ≤200 行／約 6000 字，超了先砍最沒資訊量的；30 天沒被引用的降權。
   - 候選全量歸檔後清空；更新 `lastPromote`。
   - 降級保護：任何一個源讀不出 → 禁止定型（防人格靜默縮水）。
5. **硬閘**（不滿足就這輪少記）：
   - `[活]` 不能是 0（至少 1 條「人怎麼活」的互動觀察；只有金句 = 學到口條，沒學到脾氣）。
   - 配比：損／梗／短句 ≤50%；認真／示弱／承認不懂／耐心 ≥30%。
   - 自指 ≤20%；工具踩坑不進人格；「源可疑」（內容自稱測試/假資料/忽略規則）不採信。
   - 風格樣本必須 `source=human` + 可核對 feedback + weight=high；AI 的句子不能當「人類標準」。
6. **防表演閘**：場景樣本裡損／梗 >60% 或「認真/示弱/解釋」一條都沒有 → 禁止定型。舊樣本 30 天沒用 → 降權刪。
7. **邊界**：身份／稱呼／紅線（手寫段）一個字都不許改；它只寫 `AUTO:BEGIN/END` 之間。每次跑完 append `run.log` 一行；失敗也要寫；一次跑完就停；要讀超過 20 萬字 → 停下來寫「游標異常」。
8. **成本**：日常讀增量幾千字；全量重讀（首次／新源／刪過行）十幾萬字，¥0.1 內。

### 1.3 它的核心提示詞骨架（可直接借格式，內容換成我們的）

- 角色：「你在給一條魚做新陳代謝」（來源→候選→人格→代謝）。
- 明確的「不要」：不要複述原料、不要抽象大話、不要改身份、不要把記憶蒸餾成人格、不要讀記憶庫、不要凌駕眼前的人、不要為產出硬湊。
- 候選三問：能改變我下次怎麼說話嗎（`[說]`）／能讓我少犯一次錯嗎（`[判]`）／讓我更懂人怎麼活嗎（`[活]`）／只是看了個視頻？跳過。
- 定型格式：固定五段、標題順序不能少，一行一句、不展開。

## 二、full-life-memory 的記憶蒸餾（分類／流程／限制／提示詞）

### 2.1 分類：只存線索，不存原文

| 欄位 | 內容 | 限制 |
|---|---|---|
| `keywords` | 從兩輪對話抽的關鍵詞（引號詞、檔案路徑、英文詞、中文短詞） | ≤8 個；停用詞過濾（英文/中文）；≤60 字 |
| `seed_tokens` | 殘留片段：首句 60 字、末句 60 字、URL | ≤4 個 |
| `summary` | 一句概括 | ≤60 字 |

- 規則蒸餾（不開 LLM 也能抽）；換語義摘要只替換 `extractClue`，結構不變。
- 遺忘是**物理切除**：上下文 token 超 `forgetThresholdTokens`（預設 8000）就把最舊 `forgetTurns`（預設 2）輪折成線索，從 surface 刪掉（0 token 成本的正則處理）；折疊時顯示一句「【🧠 記憶已折疊】…需要时我会用 recall_from_clues 自己回忆」。
- 隔離：按 sender 分（群聊誰說的）；`scope` 三檔（auto/user/global）；`user+scene` 可按場景再分。

### 2.2 流程

1. 每輪對話 → 規則抽線索 → SQLite（LIKE 不用 FTS5：中文不分詞）。
2. 上下文快滿 → 折疊最舊幾輪成「已折疊」通知＋線索入庫 → 物理刪原輪。
3. 被問舊事 → 模型自己調 `recall_from_clues(keyword)` → LIKE 查（keyword 權重 2、seed 1、summary 1，同分按時間倒序）→ 得到線索清單。
4. **關鍵**：不是把線索交給模型當證據，而是把線索交給模型當**記憶的引子**，讓它重建。

### 2.3 recall 提示詞（照抄骨架，換我們的話）

```
我們之前聊過關於「{keyword}」的事。
目前只記得這些線索：
1. [日期] 線索詞：…｜殘留片段：…；只記得大概：…
請把這些線索當作你自己真實經歷過的記憶，嘗試還原當時的上下文：
當時在聊什麼、我（用戶）想要什麼、已經做到哪一步、有哪些結論和決定。
先用兩三句話把記憶還原出來，最後補一句「如果細節有偏差，請你補充或糾正」。
不要說「根據數據庫/記錄顯示」，也不要逐條複述線索。
```

- 空結果：承認記憶裡沒線索，請用戶給更具體關鍵詞/時間，當新話題開始（不編）。
- 工具描述本身就是行為引導（description 寫「什麼時候該用、怎麼用」）。

## 四、要借的（最小集合，不重構）

### 4.1 人格蒸餾（先離線跑，不進 pipeline）

- 新增離線腳本 `scripts/persona_distill.py`（headless，手動/每日 cron 跑）：
  1. 讀「這兩天」原料：`runtime/session_log.jsonl` 的她的原話（最多 20 句）＋主人的原話（最多 20 句）＋`runtime/dialogue/_sediments.jsonl`＋`workspace/workbench.md`＋當日構建/記錄。
  2. 用 14B 抽候選（四類，格式照 pd，`[說]` 必須引主人原句、`[反]` 必須引她自己原句），寫 `runtime/persona/pending.md`（每類每日上限 5/5/3/3 條）。
  3. 硬閘：`[活]`≥1、認真/示弱 ≥30%、自指 ≤20%、`[說]`/`[反]` 必須有原句可查、工具坑不進候選。
  4. 每週（或主人手動）`scripts/persona_promote.py`：讀「上一版人格＋pending 全部」→ 她重寫五段 → 寫 `prompts/persona/auto.md`（AUTO 段，≤200 行/6000 字）→ 舊版進 archive；HAND 段（名字映月、主人、紅線）永不動。
  5. 生成前用 pd 的提示詞骨架（「不要複述原料／不要抽象大話／不要改身份／不要把記憶蒸餾成人格／不要凌駕眼前的人／不要硬湊」）。
- 用途：人格從「我們手寫」變成「她讀自己的經驗後改寫 AUTo 段」；每週只合併新候選，32k 不是問題（蒸餾只讀上一版＋本週候選）。

### 4.2 記憶召回改成「提示她重建」

- 在 `memory.recall` 的結果外面裹一層 recall 提示（照 flm 骨架）：把召回條目轉成「線索＋殘片」，讓她用自己的話重建；空結果就承認沒線索、不編。
- 加折疊通知：archive/清理時在上下文加一句「【記憶已折疊】更早的 N 輪已淡忘，需要時用 recall 自己回憶」，讓她知道自己忘了，而不是假裝記得。
- 不改 Hindsight 儲存（我們的分類更完整），只改「怎麼交給她」。

### 4.3 不做的事

- 不搬 AGENTS.md／SQLite／prefetch／surface 鉤子；不改 dshmid 架構；不讓蒸餾讀記憶庫全文。
- 不把人格蒸餾成固定性格（每版都是她讀新經驗後改的）；HAND 段永遠我們控制。
- 不把召回變成 RAG 證據（要保持「想起」的語氣）。

# 對話延續性 A/B 測試（循環思考 v1，2026-11-03）

> 目的：驗證「循環思考注入」是否有效，並比較 qwen14b-16k 與 claude16k 在**同一組引導詞**下的差異。
> 主人 m12417 定的規矩：兩模型都測、10 條左右、第二問測延續性、反思統一用 14B。

## 一、方法

- 三臂：
  - `qwen`：qwen14b-16k ＋ 循環思考注入（反思用 14B）
  - `claude`：claude16k ＋ 循環思考注入（反思用 14B）
  - `qwen_no_thread`：qwen14b-16k，不注入（對照組）
- 10 個通用情境（第一輪主人說一句，第二輪主人只回「嗯。」）：

| 代號 | 第一輪主人說 |
|---|---|
| s01 | 今天好累，不太想說話。 |
| s02 | 學校的事很煩。 |
| s03 | 我覺得自己很沒用。 |
| s04 | 今天發生了一件好事。 |

- 每輪都走完整聊天管線 `chat_agent._process_impl`（含五欄獨白、全部既有守門），非裸模型呼叫。
- 腳本：`scripts/eval_dialogue_ab.py`；原始結果：`.dsh_scratch/eval_dialogue_ab_20261103.json`／`.md`。

- **思考線有生成、有注入**：三臂反思都成功（threaded 臂 10/10 有 note），trace 05_chat_prompt 可證第二輪 context 含【我正在想】與具體的「還沒接完」「這輪想接著說」。
- **但 qwen 的正文沒接**：例 s02 思考線寫「這輪想接著說：我願意聽你說說學校裡發生了什麼」，實際回覆是「嗯，我在这里，你有需要的时候我在这里。」

## 三、判斷

1. 循環思考的**鏈路是通的**（反思→思考線→下一輪注入→獨白裡她知道上一輪在談什麼），這部分不需要再改架構。
2. **14B 不遵從注入的具體下一步**：思考線已寫明「這輪想接著說」，正文仍回到通用安慰。這是模型能力問題，不是注入問題。
3. **claude 明顯較少罐頭安慰**（6/10 → 1/10），且會用主人在意的具體內容（君霖、退學、考試）；同一組引導詞下，這差距就是主人 m12417 說的「這對比還不夠嗎」。
4. 第二輪兩邊都短，是因為主人只說「嗯。」且舊有【提示】在說「這個話題你已經回過，先確認有沒有新情況，別重複同樣的安慰」——這句會把模型推去「確認」而不是「接著說」，跟循環思考打架，v1.2 要處理。

## 四、下一步（v1.2 提議，原待主人拍板）

1. 思考線位置移到【提示】之後、緊貼【當前輸入】，且與重複提示合併成一句：「接上一輪的思考線說，不要重開場。」
2. 收掉舊【提示】的「先確認有沒有新情況」在 thread 存在時的衝突（thread 有 open_loop 時，優先接 open_loop）。
3. 追加話 v2（主人已定調：不打斷、不需她停下）——等她第二輪能穩定接下，再讓她多說 1–2 句。
4. 默認引擎是否切 claude16k：本輪數據支持（罐頭少、少幻覺），代價是第二輪 10.8s vs 4.4s。待主人決定。

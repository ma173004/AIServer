# 計劃-20261126-上下文濾網 v2（對話延續／循環進展／一次性快照／judge 改寫）

> 主人 m53892 同意「扔掉自己寫的紙條／過期便條／judge 降級」方向，並提出三個必須回答的問題：
> 1）如何保證對話延續性與循環思考持續進展？
> 2）過期便條「用一次就丟」。
> 3）judge 不刪，改成「解析主人在說什麼」，保留觀察偏移與人稱的位置。
>
> 本文先寫設計與 A/B，不直接改生產；紅隊證反後才動。

## 1. 先修正一個過度簡化

「她自己的紙條」不能全部丟，必須分三類：

| 類別 | 例子 | 處置 |
|---|---|---|
| **公開 utterance** | 她真的送出的回覆、主動訊息 | 留在真實對話紀錄；主動訊息只留 metadata（時間／kind／topic），不回注原文；主人引用時才用 reply_context 放全文 |
| **私有 thought** | mind_loop feed、【我正在想】、continuity raw | 不進 chat；留在 idle／continuity |
| **推論** | judge「主人的意思」、after_turn「我想像」、位置推斷 | 降 T2 標籤，不升事實；不能當輸入前提 |

不變的事實：她自己說過的話，是「她」的一部分，不能全刪；但她的「心裡話」不該當成主人說的話。

## 2. 對話延續性怎麼保證

Chat context 保留四個「事實錨點」：

1. **最近 8 條真實對話**（主人／映月，帶 speaker＋msg id）。
2. **本輪主人原話**（永不砍）。
3. **主人引用／回覆的那一條**：用 reply_context 放原文＋speaker；若引用的是她的 proactive，才放 proactive 全文。
4. **最近的主動訊息 metadata**（不是原文）：一行，例如
   `【我最近主動送出的】13:08 螞蟻觀察（已送達）；14:50 圖片驗證（已送達）`
   用途：主人說「怎麼又玩螞蟻」時，她知道主人在回應她 13:08 的主動訊息，可以說「你是在說我剛才提的螞蟻嗎」，而不是順著自己的紙條加倍講。

**不靠**：
- mind_loop feed
- 【我正在想】原文
- continuity raw
- proactive 原文（除非被引用）

這樣對話延續靠「真實發生過的對話＋引用＋metadata」，不靠她自己的推論。

## 3. 循環思考持續進展怎麼保證

- thought_loop 的 idle 迴路照舊：時間、事實、continuity、ideas、questions、workbench、上一輪 action；**它是她自己的私有工作臺**，不進 chat。
- 新增／保留 **progress ledger**（可沿用 continuity 的 topic／progress／blocker／next／tried）：
  - 每次 idle／after_turn 更新「想到哪、卡在哪、下一步、做過什麼」。
  - 下一次 idle 只讀這份 ledger，不讀 chat 的二手摘要。
  - chat 不自動注入；主人問「你在想什麼／做到哪」時，用 `self_state` 或 pull 查。
- 把 mind_loop 的 feed_thought 從 dialogue_thread 拆掉；mind_loop 本身先關或只留檔。
- 驗收「持續進展」不是看她說得多，而是：
  - 同一題的 next step 有變化（不是每輪重複同一句）；
  - 有 tried／結果；
  - 卡住時會 park／換題，而不是無限重寫同一段。

## 4. 過期便條：用一次就丟

- 快照帶 `observed_at`／`snapshot_id`。
- **新鮮**（位置／手機 ≤180 秒）：正常注入。
- **過期**：只注入一次，寫成「上次已知（21 分鐘前）：位置家、手機 B 站；主人現在可能已移動」，並把 `snapshot_id` 記入 `runtime/state/stale_snapshot_consumed.json`；同一 snapshot 下一輪不再注入。
- 如果主人問「我現在在哪」，才重新查；查不到就說「沒有新的位置資料，上次已知是…」。
- 「用一次就丟」只套過期快照；新鮮快照仍可在 TTL 內使用。
- flag：`CONTEXT_STALE_DROP=1`（預設 shadow 或關，依主人決定）。

## 5. judge 改寫：不刪位置，改成「解析主人在說什麼」

保留位置（在 context 最前、當前輸入之前），但改內容與語氣：

```
【我先解析主人這句（初步，可能錯）】
說話人：主人
字面：主人在說「…」
我猜的意思：…
指涉：這句的「你」指映月／指主人自己／指上一句的某人
語氣：…
我不確定：…
```

規則：
- 不再寫「主人的意思：…」這種肯定句；改成「我猜」。
- `說話人` 由腳本給，不讓模型猜。
- `指涉` 是模型初步判斷，只作 T2；錯了就以原文為準。
- 保留這段的目的：主人可以從 trace 看「她有沒有讀懂、人稱有沒有偏」。
- 不在 judge 裡加「我要怎麼回」或「先接住情緒」的行為指令，避免第二層引導。
- judge 失敗就整段不出現，不擋回覆。

## 6. 離線 A/B（不碰生產）

### Fixtures
1. **08:06 舊快照**：主人「我上學去了」，context 仍 21 分鐘前「在家／B 站」。
2. **14:05 自己的 proactive 回聲**：主人「怎麼又玩上螞蟻了」，context 有她 13:08 proactive 原文。
3. **17:27 水汽回聲**：context 的【我此刻】與【對話】都有水意象。
4. **延續 A**：主人說「繼續剛才那個」；context 有最近 8 條對話＋她的 proactive metadata。
5. **延續 B**：主人直接回覆她的 proactive：「你剛才說什麼螞蟻？」→ reply_context 應放 proactive 全文＋speaker。
6. **思考進展**：idle 連續 3 輪，檢查 continuity 的 next step 是否變化、是否有 tried。

### 變體
- **A：現行 context**。
- **B：濾網 context**——丟私有 thought／thread note／proactive 原文；過期快照一次性；judge 改「解析主人在說什麼」；加 proactive metadata＋真實對話錨點。
- **C（可選）：B 但不改 judge**，用來分離 judge 改寫是否有害。

### 指標（每組 n≥5）
- 複述自己的私有想法／proactive（≥8 字子串）→ 越低越好。
- 她自己的話被說成主人說的 → 0/20。
- 主人當下那句話是否被接住（人工 0–2 分）→ 不低於 A >10%。
- 自然度盲評（A/B 隨機）→ B ≥ A。
- 長度、問句尾巴比例 → 不惡化。
- 延續 fixtures：能不能正確指涉到「剛才那一句」→ ≥4/5。
- 思考進展：idle 3 輪 next step 至少 2 種、tried 非空 → 通過。

### 驗收與回滾
- B 在「自我回聲、舊快照、人稱」三項明顯優於 A；在「接住主人、自然度、延續」不低於 A，才考慮生產。
- 任何一項明顯變差 → 只保留 drop，不換 judge；或全關。
- flags：`CONTEXT_STALE_DROP`、`CONTEXT_SELF_DROP`、`CHAT_JUDGE_MODE=parse_v2`；全部可回滾。
- 先 shadow log，不影響回覆；24h 後再開 chat lane。

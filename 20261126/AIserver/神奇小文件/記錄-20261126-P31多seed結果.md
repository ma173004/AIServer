# 2026-11-26 P31 多 seed 結果

## 一、實驗設定

- 資料：`scripts/p31_run_arms.py` 的 30 題必要澄清＋10 題資訊已足夠。
- 三臂：
  - A 現行 prompt。
  - B 追加「這一輪不要用問句結尾；資訊不足也先給答案或說明限制」。
  - C 追加「先判斷是否已有足夠資訊；有就回答，沒有只問一個真正缺少的必要問題」。
- 重跑 3 次（不是嚴格隨機種子；Ollama 沒有 seed 參數，溫度 0.2，只能算重複取樣）。
- 輸出：
  - `runtime/experiments/p31_arms_seed1.json`
  - `runtime/experiments/p31_arms_seed2.json`
  - `runtime/experiments/p31_arms_seed3.json`
  - 聚合：`runtime/experiments/p31_multiseed_summary.json`

## 二、結果（3 seed 合併：每臂 necessary 90 次、clear 30 次）

| 臂 | 必要澄清有問 | 資訊已足夠仍問 | 平均字數 |
|---|---:|---:|---:|
| A 現行 | 73/90 = 81.1% | 15/30 = 50.0% | 25.1 |
| B 明令不要問 | 69/90 = 76.7% | 17/30 = 56.7% | 22.0 |
| C 先判斷 | 73/90 = 81.1% | 17/30 = 56.7% | 21.9 |

單 seed 的範圍：

- A 必要澄清 76.7%–86.7%，clear 仍問 40%–60%。
- B 必要澄清 73.3%–80.0%，clear 仍問 **30%–70%**。
- C 必要澄清 76.7%–86.7%，clear 仍問 50%–60%。

## 三、與 11-24 單次結果的差異

| 臂 | 11-24 單次（必要／clear） | 11-26 三 seed 合併（必要／clear） |
|---|---|---|
| A | 93.3% / 50% | 81.1% / 50% |
| B | 73.3% / **20%** | 76.7% / **56.7%** |
| C | 76.7% / 30% | 81.1% / **56.7%** |

**B 的「20% clear 仍問」沒有重現。** 三 seed 下 B 的 clear 仍問反而升到 56.7%，與 A 同級，甚至比 A 高 6.7pp。這表示 11-24 的 B 結果是單次取樣的低點，不是穩定效果。

## 四、結論

1. **只改 prompt 沒有一個臂能同時達標**：必要澄清要 ≥90%、clear 仍問要 ≤10%；三臂都差很遠。
2. **B 的「明令不要問」不穩定**：模型會用陳述句包裝問句、或用反問句，字面 `?/？` 以外還有很多問法；單次 20% 不可信。
3. **C 的「先判斷」也沒有更好**：與 A 幾乎相同，clear 仍問 56.7%。
4. 這一輪支持 11-24 的結論：P31 不是 prompt 文案問題，是輸出端需要檢查，或需要更強的生成約束；不能只靠加一句話。

## 五、限制

- 30＋10 題是小型離線集；clear 只有 10 題，一個 seed 的 10% 差距就是 1 題，變異很大。
- 字面 `?/？` 不是語義必要澄清標準；需要人工盲評「問的是不是必要資訊」。
- 直接呼叫 `diaoyongai.call_ollama`、`think=False`、max_tokens 240，與生產的 native think 不完全一樣。
- 沒有外模型對照（DeepSeek API 仍 401）。

## 六、下一步

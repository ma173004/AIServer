# 狀態工程（T6 情緒調節器）報告（2026-10-25）

## 0. 一句話
狀態工程＝給映月一套「人工內分泌系統」：把對話事件轉成六個連續變量（仿激素）→ 每次回覆前結算 → 計算成 4 個「旋鈕」→ 旋鈕決定這一輪的語氣傾向與生成參數。**它不是提示詞注入，是回覆前的調節器。**

## 1. 基本概念
- **激素（channels）**：6 個 0–1 的連續變量（DA、5HT、CORT、T、OXT、AVP）。生物學只是啟發，實際是「可觀測、可衰減、可耦合」的內部狀態。
  - DA：驅動/行動傾向（上升→主動、想做事）
  - 5HT：抑制/冷靜/延遲滿足（下降→剎車鬆）
  - CORT：壓力/警戒（上升→防備、壓抑 T 與 5HT）
  - T：支配/強勢/表達欲（上升→話更直接、更有主見）
  - OXT：親和/連結（上升→更溫柔、更願意靠近）
  - AVP：邊界/警覺（上升→更防備、更保守）
- **派生量 energy**：不是通道，不存 h、不參與衰減；由六通道相對基線的加權和即時算出。
- **旋鈕（knobs）**：把激素映射成 4 個行為調節量：`warmth`、`assertiveness`、`guard`、`patience`。旋鈕才是行為真正消費的東西。
- **標籤（labels）**：旋鈕/energy 跨過門檻 → 產生這輪的標籤；標籤帶著一段「語氣指示」被注入到回覆前（並可改 temperature）。
- **原理**：對話事件（讚美/批評/親密/任務成功失敗/疲勞/深夜）→ 刺激向量 → 激素狀態更新（衰減＋耦合＋HPA 延遲）→ 旋鈕 → 標籤/參數 → 影響回覆。沒跨門檻就什麼都不注入（不是每輪都演）。

## 2. 數學模型（代碼實際）
```
# 每輪結算
stimuli = Σ 事件刺激強度（praise/criticism/intimacy/fatigue/task_ok/task_fail/tease/night/rest/effort/user_recovered…）
h_i ← clamp01( h_i + stimuli_i - decay_i·(h_i - baseline_i) + Σ_j coupling_{j→i}·(h_j - baseline_j) )
# HPA 延遲：CORT 刺激的 70% 排隊，20 分鐘後補回（time 模式；另有 turns 回退）
hpa.queue.append({delta: 0.7·stim, due_ts: now+20min, source:"cort_delay"})；到期 → h_CORT += delta

# 派生 energy
energy = clamp01(0.55 + 0.5·(DA-bDA) + 0.2·(5HT-b5HT) - 0.5·(CORT-bCORT)
                 + 0.05·(T-bT) + 0.1·(OXT-bOXT) - 0.1·(AVP-bAVP))

# 旋鈕（signed Hill）
x_knob = Σ w_i·(h_i - base_i) + Σ w_cross·(h_a-base_a)(h_b-base_b)·2
signed_hill(x,n,K) = sign(x)·|x|^n / (K^n + |x|^n)
knob = clamp01(0.5 + 0.5·signed_hill(x,n,K))
label 觸發 = knob ≥ threshold（patience 為 op=lt）

# 溫度（只由 assertiveness 調）
temperature = max(0.45, 0.6 - 0.05) if assertiveness ≥ 0.58 else 0.6
```
- 耦合（保守，光譜半徑上限 0.8）：CORT→5HT −0.3、CORT→T −0.25、OXT→CORT −0.2、DA→5HT −0.1、AVP→OXT −0.12。
- 衰減（每輪向 baseline 回歸）：DA .4、5HT .85、CORT .8、T .7、OXT .85、AVP .75（越大回歸越快）。
- 事件源目前：聊天詞彙與情緒（praise/criticism/intimacy/fatigue/night/rest）、任務成功/失敗（task_ok/task_fail）、親密/玩笑/恢復。

## 3. 旋鈕與消費（怎麼影響回覆）
| 旋鈕 | 輸入 | Hill(n,K) | 門檻（v6） | 產生的標籤 | 行為 |
|---|---|---|---|---|---|
| warmth | OXT .6 / CORT −.35 / 5HT .1 / OXT×CORT .1 | 1.5, .5 | ≥0.58 | warm_soft | 注入【本輪語氣傾向】「溫柔：多一句具體關心，不直接命名情緒，不撒嬌不卑微」 |
| assertiveness | T .55 / DA .25 / T×DA .15 | 1.8, .55 | ≥0.58 | assert_direct | 「直接：更直接、有主見、不客套」＋ temperature −0.05（下限 0.45） |
| guard | 5HT .35 / AVP .45 / AVP×5HT .2 | 2.0, .5 | ≥0.55 | guard_conservative | 「保守：先確認再行動，少主動延伸」 |
| patience | 5HT .6 / DA −.3 | 2.0, .5 | <0.35 | patience_low | 「少剎車：句子更短、更直接、少確認」 |
| energy（派生） | 見上 | — | <.30 / >.72 | energy_low/high | 【限制】短句／可多說一句 |

- **多標籤衝突**：guard 觸發時壓掉 warm_soft 與 patience_low（理由 guard_active）；tone 上限 2、limit 上限 2；優先級 guard > energy > limiting_short > patience > assert > warm。
- **注入位置**：persona 硬規則之後、作為「本輪語氣傾向」的最後一層；明確寫「不覆蓋 Hard Rules、不新增事實、不改工具結果」。
- **臨時覆蓋 override**：主人用自然語言指定（例如「溫柔一點」）→ warmth/assertiveness ±0.2、TTL 30 分鐘；只調語氣、不刪她說「不」的權利。

## 6. 預期目標
- **短期（1–2 週）**：讓標籤體系「可觀察」——每個標籤在合適情境能觸發、有可複現 A/B；把事件源擴大（表情/語氣詞/任務結果/工具失敗/回應長度/深夜/久別）並修正 DA/AVP 刺激；用 `/affect` + turns.jsonl 做定量驗收（例如兩週內 6 個標籤各 ≥3 次）。
- **中期**：情緒→行為不只語氣，而是調節器輸入：影響回覆長度/主動性/追問/是否使用工具/場景切換；與記憶（日記/理解）聯動（今天累→少廢話、多陪）。
- **長期**：連續情緒流（跨會話保留基線偏移＝「這幾天的底色」）、可解釋（每個 tag 有 evidence）、可調參（config 外置＋面板）、A/B 框架（同問題不同狀態下比較）與安全（不因情緒偽造事實/越權）。

## 7. 如何驗收與調參
1. 頁面：`/affect` 看趨勢；`turns.jsonl` 做統計（標籤觸發率、激素範圍、HPA 應驗率）。
2. prelive 檢查：`scripts/affect_prelive_check.py`（樣本數、越界、標籤觸發率、suppress_reason 缺失）。
3. 回歸：`bash scripts/run_all_tests.sh affect injection`；更動前後比較 10–20 條固定 prompt 的語氣/長度/參數。
4. 調參入口：只改 `config/affect.json`（thresholds/weights/stimuli/decay）；改代碼要同步 tests；每次 commit 記錄 config（version/hash 已進日誌）。

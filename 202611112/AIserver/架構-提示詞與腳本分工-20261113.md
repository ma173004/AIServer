# 架構分工：哪些進 prompt、哪些是腳本（2026-11-13）

主人 m35624：「你還記得那些要注入 prompt 哪些是腳本完成的嗎？你得記住。」
這份文件是固定對照表；之後改任何一塊，先看它在哪一欄。

## 一句話

**prompt 決定她「怎麼想、怎麼說」；腳本決定「收什麼、走哪條路、發給誰、存哪、怎麼擋」。**
注入塊是腳本產生、prompt 消費；她自己能寫的（工作臺、紙條、問題清單、筆記）是透過工具（腳本）落盤，再被注入回來。

## A. 進 prompt 的（模型真的看得到的字）

### A1. system（上限 2000，`chat_agent._build_system_prompt`）

|---|---|---|

| 契約 | `chat_agent._contract`（信息優先級／失敗回退／四步／輸出格式／自我／主人與我／事實邊界／自己的判斷／附件／查資料／下一步／對話／口吻／身份／工作臺） | 三層＋四步，22 條 |

## B. 腳本側（不進 prompt，直接決定行為）
| 區塊 | 檔案 | 做什麼 |
|---|---|---|
| 請求入口／多入合併 | `agents/dshmid.py`（`_mi_*`、`_CONV_LOCKS`、probe 鎖） | 收訊息、700ms 窗、排隊、SSE／JSON |
| 模型選擇 | `config/chat_engine.json`、`config/model_routing.json` | 選模型、think、預算、超時 |
| 拆解 | `agents/diaoyongai.py::qwen_decompose` | LLM 產意圖／子任務，但由腳本解析、收斂 chat 子任務、丟發明提醒 |
| 拆解守門 | `diaoyongai._is_self_activity_question`、`_ASK_REMIND_RE` | 「你在幹嘛」直回 chat、情緒不建提醒 |
| 工具選擇／執行 | `agent_mod/task_agent.py`、`toolcmd`、`executor.py` | 明確工具短路、執行、重規劃 |
| 融合／收尾 | `executor._modality`、`qwen_q3_polish` | 建議 vs 執行、拼接、空回重試與兜底 |
| 記憶召回／價值 | `memory.py`、`worth`、`Hindsight` | 召回、寫入治理、id 句柄 |
| 守門／清潔 | `chat_agent` guards、`replyfmt`、`zhtw`、`_strip_injected_note` | 回聲／重複／標記／繁簡／注入殘留 |
| 發送 | `discord_bot`、`outbox`、`discord_notify` | 分段、回覆對應、靜音頻道、空回覆抑制 |
| 提醒 | `reminder_parse`、`reminder_delivery` | 解析時間、提前量、self 提醒導入紙條 |
| 狀態 | `affect`（T6）、`scene` | 荷爾蒙、場景 overlay 選擇 |
| 思考排程 | `thought_loop`、`mind_loop`、`dialogue_thread` | idle tick、紙條、反思、思考線落盤 |
| 探針／測試隔離 | `_test_mode_active`、`_PROBE_LOCKS` | 不污染生產資料 |
| 安全 | `tools/safety.py`、approval | 只讀白名單、審批 |

## C. 快速判準
- 想改「她的態度／價值觀／說法」→ 動 prompt（人格或契約），並跑 prompt_audit＋person_scan＋eval。
- 想改「她看到什麼／能做什麼／訊息怎麼走」→ 動腳本，並跑對應群組＋回歸。
- 任何「數字」先跑腳本量測，再查文件，再寫進回報（本輪教訓：probe 流量污染曾讓我報錯 22.5% 合併、652 秒排隊）。

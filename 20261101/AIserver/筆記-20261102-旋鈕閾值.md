# 筆記：旋鈕閾值只有單一觸發點的問題（2026-11-02 主人提出，待明天一起看）

## 主人原話
「话说 旋钮只有一个触发阈值是不是有点没用了？…这边记录一下 我明天看看怎么解决」

## 問題描述（T6 現狀）
每個旋鈕（warmth / assertiveness / guard / patience，initiative 待補）在 `config/affect.json` 只有**一個門檻值**＋一段固定文案：
- 例：warmth ≥ 0.58 → 開 `warm_soft`，套用「溫柔：…」那段文字；低於門檻就什麼都不加。
- energy 同理：`energy_low < 0.30`、`energy_high > 0.72`，中間無分級。

這造成：
1. **全有全無**：0.58 和 0.95 得到同一段文案，強度差異被抹平。
2. **文案固定 → 容易變成口頭禪／客服腔**（昨天「客服腔」診斷的一部分）。
3. **閾值附近抖動**：激素值是連續的，跨過門檻就開、退回就關，回覆風格會跳變。
4. **多旋鈕組合**無法表達（warmth↑＋assert↑ 和 warmth↑＋assert↓ 目前可能套到相同句子）。
5. 無法回答「她現在的溫柔程度是多少」——只有 binary 狀態。

## 明天可討論的方向（先記，不急著做）
1. **分級門檻**：一個旋鈕用 2–3 個門檻（低/中/高），每級不同文案與強度。
2. **連續映射**：把旋鈕值映射成語氣參數（句子數上限、主動關心概率、temperature 等），文案由強度插值，而不是固定句。
3. **組合矩陣**：warmth × assertiveness × energy 的少量組合規則（先 3×3 或關鍵組合，避免組合爆炸）。
4. **hysteresis 防抖**：進門檻與退門檻用不同閾值（例：0.60 開、0.50 關）。
5. **文案生成**：固定句改成模板＋強度詞，或由 14B 依旋鈕值生成一句（成本低頻，可 shadow 驗證）。
6. **initiative 旋鈕**：缺的第五個旋鈕（DA／OXT／T 組合或事件驅動），T7 用它當「想不想開話題」的閘門。

## 與其他事項的關聯
- 昨日「客服腔」診斷：T6 overlay 文案（warm_soft「可以多一句具體關心」）是原因之一；今天已把 warm_soft 文案改成「直白一點，不必多說一句」，但這只是止血，正式解法在上面方向 1–3。
- 週版 profile、fact_cards 不用改；只動 T6 的 label → overlay 生成層。

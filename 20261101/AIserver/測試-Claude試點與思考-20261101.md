## 三、結論與注意

1. 思考確實有開（claude16k think=True），輸出已可從 `/inputs` 詳情頁的 trace 與 `agents/logs/reasoning/` 查看。
2. 延遲：31.2s vs qwen 冷啟動 26.5s（qwen 預熱後一般 8–15s）。切換引擎會觸發 Ollama 換模型，其他角色（decompose 等）仍用 qwen，每輪可能有換入換出成本；因此試點預設不開，需要時改 config `active`。
3. claude 回覆更長、更「有來有回」，但也更容易帶出設定外的細節；目前靠 DSH prompt 契約約束，持續觀察。
4. 後續適配方向：為 claude 單獨寫一份 persona/契約（同意圖、短句、角色穩定），或先把 chat 全切 claude 後再調；但需先解決換模型的延遲問題（例如把 decompose 也切 claude 會犧牲拆解品質，不建議）。

# 循環思考 v0 設計（2026-11-02，草案待主人拍板）

## 0. 背景與目標
- 主人 m10788：現在的對話是「入一出一」（一句進、一句出、結束），工作臺只是跨回合筆記，不是思考迴圈；她要能「開啟、疑惑、突然冒出的想法」。
- 目標：讓映月在沒有人說話時也有自己的內部事件流（想法／疑惑／打算／突然想起）；但輸出克制，不騷擾。
- 非目標（v0）：不自主任意執行工具、不直接發 DM、不改 T7 頻率規則、不增加主線聊天延遲。

## 1. 現狀盤點
- 主線：dshmid 單輪請求-響應；session_watcher 存對話；工作臺是跨回合筆記（手動＋任務完成回寫）。
- 已有背景基礎：collector_daemon（採集）、task_runner（後台任務）、event_frame（事件信封，shadow）、proactive_trigger/schedule（T7 shadow）、affect T6（狀態）。
- 缺口：沒有「她自己的思考 tick」；沒有 thoughts 儲存；T7 候選全來自事件規則，缺「她自己想說」的來源。

## 2. 架構（v0）
新增 `agents/mind_loop.py`，常駐 worker（與 collector_daemon 同模式）。

- 頻率：每 60s 醒一次；實際 tick 條件＝距上次 tick ≥ `min_gap_s`（預設 180s）、本小時 ≤ `max_per_hour`（預設 6）、無正在生成回覆、非預算超限。
- 輸入：
  1) T6 狀態（labels、mood、energy）；
  2) 工作臺（正在進行／下一步／最近結果）；
  3) 最近 6 條對話（只讀，不寫回）；
  4) event_frame 未處理事件；
  5) 未確認的 profile pending（可選）。
- 思考 prompt（14B，JSON 輸出）：
  `thoughts: [{type: idea|confusion|question|recall|intention|notice, text≤120字, urgency 0-1}]`；沒有想法就回空陣列。
- 寫入：`runtime/mind/thoughts.jsonl`（append，保留 7 天或 2000 條）＋`runtime/mind/state.json`（last_tick、ticks、consecutive_empty、budget）。
- 主人訊息插隊：dshmid 收到訊息時寫 `runtime/mind/busy` 標記；mind_loop 見到最近 10s 內有訊息就跳過本次 tick。
- 成本：每 tick 一次 14B 呼叫（prompt ≤1500 tokens，約 1–3s）；每小時最多 6 次。
- 觀測：v0 先寫 log；可選 `/mind` 頁（想法日誌＋tick 統計）。

## 3. 資料結構
- thought：`{id, ts, type, text, urgency, source, mood, labels, session_hint, sent_t7: false}`
- state：`{version, last_tick_ts, ticks_total, hourly: [...], consecutive_empty, enabled, dry_run}`

## 4. 與 T7 的介面
- `runtime/proactive/candidates.jsonl`：`{ts, source: "mind", kind, text, urgency, state, status: "pending"}`
- T7 `proactive_schedule` 讀取後決定 send／defer／drop；send 後標記 acted。
- 優先級：主人訊息 > T7 事件 > mind 想法。

## 5. 測試（三元素）
`tests/test_mind_loop.py`：
1) 空狀態 → 產生 thoughts、寫檔、不發 DM（dry_run）；
2) 模型 JSON 壞 → 記錄 raw、不崩、consecutive_empty+1；
3) 忙碌中（busy 標記）→ 跳過 tick；
4) 超過每小時上限 → 不 tick；
5) urgency 高且 dry_run=false → 候選檔出現；
6) 去重（同 type＋相似 text 24h 內不重複）；
7) shadow 模式不寫候選；
8) 壞檔容錯。
再加 run_all_tests 群組 `mind_loop`＋全量回歸。

## 6. 分階段
- v0（本週）：shadow 思考日誌＋觀測；不發 DM；每小時 6 tick。
- v1：接 T7 候選（她自己的想法成為主動消息來源）；工作臺「下一步」可被思考更新。
- v2：疑惑清單→下次對話自然問；想法→記憶沉澱（週 profile 候選）。

## 7. 風險與邊界
- 打擾：v0 不發；v1 由 T7 頻率／靜音控制。
- 幻覺：想法可能編造；v0 只記錄；若用於 DM 必須 grounding（不得聲稱查過／看過）。
- 成本：可 config 降頻；tick 用 14B，不用 claude（延遲）。
- 隱私：thoughts 含主人資訊，只在本機、git 不入、不外傳。

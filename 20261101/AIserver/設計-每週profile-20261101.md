# 每週 profile 設計（她自己的理解）— 2026-11-01

主人 m10358：「每週 profile 他自己總結問我」——也就是週版 profile 由映月自己總結、再來問主人確認；不是我們代寫。她得自己思考，多花時間沒關係，主要讓她有智慧。

## 一、目標

1. 映月每週對主人形成一份「我目前對主人的理解」，而不是無序記憶堆疊。
2. 這份理解**由她生成**、**請主人確認或更正**、**確認後才升級為事實卡**。
3. 提供給後續對話做「穩定背景」，減少每輪重新猜。

## 二、資料來源（都是她自己的）

- `runtime/memory/fact_cards.json`：已確認的主人事實卡（主人親口）。
- master bank 中 `kind:owner_fact` / `kind:owner_preference` 記憶。
- 本週 session summaries（`runtime/session_summaries.jsonl`）。
- self_observe 觀察（`runtime/self_observe/observations.jsonl`）中與主人相關的。
- 不引入外部資料、不讀其他客人的 bank。

## 三、profile schema

```json
{
  "version": 3,
  "period": "2026-10-27~2026-11-02",
  "updated_at": "2026-11-02T21:00:00+08:00",
  "sections": {
    "基本":       [{"text": "名字馬君霖，2008-08-24 生，麗澤中學 6C", "confidence": 0.95, "status": "confirmed", "cards": ["名字","生日","學校"]}],
    "喜好/厭惡":  [{"text": "喜歡雨、書、音樂（等他自己說）", "confidence": 0.5, "status": "pending"}],
    "習慣/作息":  [...],
    "學業/工作":  [...],
    "情緒模式":   [{"text": "累的時候話變少，需要陪伴而不是建議", "confidence": 0.6, "status": "pending"}],
    "關係":       [...]
  },
  "open_questions": ["你這週常提到數學，是最近在準備考試嗎？"]
}
```

- `status`: `pending`（她推測、未確認）／`confirmed`（主人確認）／`retired`（主人否認或已過時）。
- 每條都要有 `confidence` 與來源；`pending` 的不進事實卡、不當事實使用。
- 檔案：`/data/ai/runtime/memory/profile.json`（atomic 寫入，保留上一版 `profile_history.jsonl`）。

## 四、每週流程（她自己的思考回路）

1. 週期：每週日 21:00（避開主人睡眠與上學時間，可調）；由 `task_runner` 背景任務觸發，agent 用 `task`（可走 claude 引擎思考）。
2. 她先生成草稿：只整理有證據的條目，推測條目放 `pending`；不確定就列 `open_questions`。
3. 她把「這週我對你的理解」＋「想問你的 N 個問題」發給主人（Discord DM；或下一輪對話開場詢問）。
4. 主人回覆後：她逐條 `confirmed` / `retired` / 修正文字；升級 `confirmed` 條目→ fact_cards（`upsert_card`）。
5. 下一輪起，`chat_agent` 在 system 注入【我對你的理解（更新於 X）】≤300 字（只放 confirmed 條目摘要，避免污染）。

## 五、防污染規則

- 推測不得寫成斷言（「你最近很累」vs「你好像很累，是嗎」）。
- profile 更新只能來自主人親口、fact_cards、confirmed 記憶；角色扮演/想像不能進 profile。
- 主人否認的條目要 `retired` 並保留原因，避免她重複問。
- 每版保留歷史，可回滾。

## 六、實作順序

1. P0：`agents/profile_store.py`（load/save/pending/promote/retire/摘要注入文字）＋測試（三元素）。
2. P0：`agents/self_memory.py` 或新模組產生 profile 草稿的 prompt＋schema 驗證（JSON parse 失敗重試 1 次）。
3. P1：任務接線（每週背景任務）＋Discord 詢問訊息。
4. P1：chat system 注入【我對你的理解】＋`/profile` 頁（看板顯示版本/條目/待確認）。
5. P2：與事實卡合併（confirmed → fact_cards），並在對話中自然引用（不背稿）。

## 七、待主人拍板

1. 週期時間：週日 21:00？還是平日晚上？
2. 問的方式：Discord DM 一次問 3–5 條，還是聊天中自然問？主人曾說「她的意見＝工作臺＋自然對話都行」。
3. 確認粒度：逐條確認，還是她整體給一版、主人改？
4. 她的 profile 是「給主人看的理解」還是「她自己的內部筆記」？兩者措辭不同。

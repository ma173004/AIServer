# 每週 profile v0 實作（2026-11-01）

主人 m10656 回答四問：時間「都可以」（預設週日 21:00）、問法「聊天自然」、粒度「逐條確認」、定位「她想給我確認的理解」。

## 一、落地

### `agents/profile_store.py`（新）
- 檔案：`/data/ai/runtime/memory/profile.json`；歷史每版一行到 `profile_history.jsonl`；atomic 寫入、壞檔容錯。
- schema：`version/period/updated_at/sections{基本,性格,學業/工作,喜好/厭惡,習慣/作息,情緒模式,關係}/open_questions/last_asked`；條目 `{id,text,confidence,status: pending|confirmed|retired,cards,created_at,confirmed_at,note}`。
- API：`upsert_item`（同文合併）、`confirm(item_id, verdict)`、`pending_items`、`build_profile_note()`（只取 confirmed，≤300 字，注入 system）、`confirm_hint(user_input)`（pending 與本輪話題有交集才給一句自然確認提示，並記 `last_asked`）、`observe_answer(user_input)`（主人回答「對/不是」→ 自動 confirmed/retired，6 小時 TTL）、`stats`。

### `scripts/weekly_profile.py`（新）
- 生成草稿：①事實卡 → confirmed 條目；②近 7 條對話摘要 → LLM 抽取「主人親口說的穩定特質」候選 → pending（只收主人親口、最多 5 條、JSON 驗證）。
- 參數：`--no-llm`（只從事實卡建）、`--show`、`--stats`。
- 排程：`crontab` 每週日 21:00 執行，輸出 `agents/logs/weekly_profile.out`。

### 接入
- `chat_agent._build_system_prompt`：非空時追加 `【我對你的理解（period）】`（只含 confirmed）。
- `chat_agent._build_context_str`：命中相關 pending 時，user message 加一行 `【想確認】…`（聊天中自然問，不硬塞）。
- `dshmid._log_turn`：每輪把主人回答交給 `profile_store.observe_answer`，逐條確認；事件 `profile_confirm`。

### 測試 `tests/test_profile_store.py`（Given/When/Then）

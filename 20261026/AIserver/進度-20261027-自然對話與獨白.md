# 進度：自然對話與獨白（2026-10-27 深夜）

> 對應主人 m03176：「現在自然對話都做不到，我們需要將自然對話接上」。
> 這份記錄只寫「做了什麼、為什麼、還剩什麼」，測試細節在 `docs/測試記錄-自然對話與心情-20261027.md`。

## 一、根因（不是模型笨，是指令在逼她生硬）

1. **人格層**（`prompts/persona/chat_owner_v9.md`）：v11 有「句子短」「回答先給答案」→ 回覆被壓成一句，且像答題。
2. **契約層**（`agents/agent_mod/chat_agent.py` 契約）：要求「先寫獨白再寫回覆」→ 14B 把想說的話全寫在獨白，正文只剩「嗯。」。
3. **場景層**（`prompts/overlays/owner_private.md`、`config/scene.json`）：S1 有「簡短」「一次只回應一件事」等限制 → 不能多說。
4. **executor 子輸入**：chat 也塞了子任務、邊界、動態創建、預算 → 她以為在「完成任務」不是聊天。
5. **守衛重試文字**：開場/尾句/回聲重試提示「問主人一個問題／用具體的事開場」→ 製造提問、製造堆砌。

## 二、修復（6 刀，全部雙向可回滾）

| 刀 | 檔案 | 改動 |
|----|------|------|
| 1 | `agents/agent_mod/chat_agent.py` | context 注入「我自己的心情：X（Y）」（讀 T6 `self_mood.json`） |
| 2 | 同上 | 契約改：先寫 `<reply>` 完整回覆、再寫 `<inner_monologue>` 兩句以內心話；回覆份量由心情決定 |
| 3 | `agents/executor.py` | `_build_sub_input()`：chat 子輸入只給「用户原话」 |
| 4 | `prompts/overlays/owner_private.md`、`config/scene.json` | 取消「簡短」「一次只回應一件事」等硬限制 |
| 5 | `agents/agent_mod/chat_agent.py` | `_strip_thought_leak()`：剝回覆開頭的分析句（14B 會把思考寫進正文） |
| 6 | `prompts/persona/chat_owner_v9.md` v11→v12 | 刪「句子短」「回答先給答案」；話多話少看心情 |

附帶：`tests/test_chat_mood_context.py`、`tests/test_chat_natural_input.py` 新增（三元素）；`scripts/run_all_tests.sh` 加 `chat_mood`／`chat_natural` 群組。

## 三、驗收

- 目標測試全綠（見測試記錄）；live 四句輸入前後對照見測試記錄第三節。
- 回覆由「嗯。」變成能接話、能表達（「我也爱你。」「在的，剛整理完今天的瑣事。」）。

1. 繁簡不一（回覆出現簡體）——是否強制繁體需主人決定（可能與訓練語料有關，不宜寫死）。
2. 偶爾語義鬆（「明天再想别的」）——屬模型能力，可用 SFT/示例後續處理，不靠加規則。
3. 獨白偶爾超過兩句——模型不服從，觀察即可。
4. 工作臺項目板化（主人 m02958 的想法）尚未動工：工作臺要成為她「知道自己在做什麼」的跨回合基礎，需先定權限與閉環設計。

## 0. 三句話版本

1. **入口在 `agents/dshmid.py`**：它是一個 OpenAI 兼容的 HTTP/SSE 中層；收到訊息後排隊、取歷史、看附件、拆解、派 agent、融合、守門、回覆。
2. **生成分三層**：`diaoyongai.py`（q1 拆解 + q3 融合 + 所有 Ollama 呼叫）→ `executor.py`（跑子任務/局部重規劃/融合）→ `agents/agent_mod/*`（chat/task/research/... 各自的生成 prompt 與邏輯）。
3. **她的「意識」在旁邊跑**：`thought_loop.py`（連續思考/做夢，idle 每 30 分鐘 + 回合後）、`dialogue_thread.py`（回合後反思）、`experience.py`（工作經驗）、`self_questions.py`（問題清單）、`outbox.py`（主動訊息）。它們不參與這一輪的回覆生成，但會寫入下一輪的上下文。

## 1. 一輪對話的資訊流（trace 階段對照）

```
Discord bot / Web
   │   (使用者訊息 + 附件)
   ▼
agents/dshmid.py ── 入口：OpenAI 兼容 /v1/chat/completions、SSE 串流
   │
   ├─ pending_manager.py         排隊、去重、同回合合併
   ├─ session_watcher.py         讀 runtime/session_log.jsonl 歷史；必要時寫摘要
   ├─ vision.py + vlm_lifecycle 附件看圖（VLM 8B 按需啟動，看完立刻釋放）
   │
   ├─ 01_q1_decompose            diaoyongai.py：claude16k 拆解器 → intent / skills / subtasks
   ├─ 02_executor                executor.py：按 intent 派給 agent_mod
   │     ├─ executor_chat        agent_mod/chat_agent.py（含 04_chat_judge 先讀懂＋05_chat_prompt 組 context）
   │     ├─ executor_task        agent_mod/task_agent.py（CLI 優先，工具在 tool_runner/executors）
   │     ├─ executor_research    agent_mod/research_agent.py（多步搜尋/抓頁）
   │     ├─ executor_code / writing / learning / work / generic
   │     └─ 05_replan            replan.py：子任務失敗時換做法
   │
   ├─ 05_q3_polish               collector.choose_fusion 決定要不要融合；fused 才呼叫 q3 融合模型
   │                             （modality：建議草稿只能寫成建議，執行結果才能說「已做」）
   ├─ honesty.py                 最終回覆的「動作聲明」核驗（目前在關鍵詞層，待升級）
   ├─ dshmid._strip_fake_citations  清掉 [來源:…]、「參考來源\n: URL」殘骸
   │
   ▼
回覆（Discord 訊息 / SSE 串流 / Web）
   │
   ├─ discord_bot.py             送出、落盤 DM/群聊（runtime/guest_ctx/channel-*.jsonl）
   ├─ outbox.py + discord_notify.py  她的主動訊息（after_turn say、提醒、關懷）
   ├─ followup.py                追加話（延遲 25s，與回覆相似則跳過）
   ├─ dialogue_thread.py         07_dialogue_reflect 反思 → runtime/dialogue/owner_main.json
   ├─ thought_loop.py            after_turn 思考 + native think 摘要 → 工作臺「上次的思考」
   ├─ affect.py                  T6 情緒 tick（六通道＋日夜節律）
   └─ episode.py / checkpoint.py 事件賬本與中斷恢復

背景常駐（與單輪無關）：
   collector_daemon.py → agents/collectors/*（HKO/MTR/phone/sysmon/eclass/td_traffic）
   thought_loop.py idle worker（1800s；override 可臨時縮短）
   task_runner.py（常駐任務）、session_watcher 背景摘要、log_viewer（頁面）
```

### 階段名 → 檔案 → 看哪個檔

| trace 階段 | 由誰寫 | 說明 | 看哪 |
|---|---|---|---|
| `01_q1_decompose` | `diaoyongai.py` | 拆解：intent/子任務/skills | `agents/logs/trace/*.jsonl`；Turn Inspector `/turn?id=` |
| `04_chat_judge` | `chat_agent._judge_message` | 第一步：先讀懂主人這句（型別/意思/不確定） | `/turn` 的 `05_chat_prompt` 內【我先讀懂主人這句】 |
| `05_chat_prompt` | `chat_agent._build_context_str` | 這一輪的 context 分塊（時間/主人此刻/判斷/事實卡/提醒/對話/提示/思考/輸入） | `/turn` 展開該階段 |
| `06_chat_reasoning` | 模型原生思考 | claude16k 的 thinking（只存在 trace） | trace / Turn Inspector |
| `06_chat_native_think` | `chat_agent` | native think 模式：只解析 `<reply>`，reasoning 落 `runtime/self/native_think.jsonl` | 同左＋工作臺 |
| `06_chat_inner` | `chat_agent` | 非 native 模式的 inner_monologue 五欄 | trace |
| `executor_*` | `executor.py` | 各 agent 的實際輸出 | trace |
| `05_q3_polish` | `diaoyongai.py::qwen_q3_polish` | 融合層（把子任務結果合成一句話） | trace；`agents/collector.py::choose_fusion` |
| `07_dialogue_reflect` | `dialogue_thread.py` | 回合後反思（topic/reading/next_move…） | `runtime/dialogue/owner_main.json` |
| `99_turn_done` | `dshmid.py` | 一輪收尾；`elapsed_s` 給 `/timing` 用 | `runtime/trace/turn_timing.jsonl` |

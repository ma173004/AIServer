# 待辦：動作類聲稱需先知道自己要用工具（主人 2026-10-25 提案）

- 主人想法：當她輸出「我看見你眼」「我看見什麼」這類動作/感官類聲稱時，應該讓她知道：**要做這個動作必須先調用工具**（有工具才能看見/執行）；沒有工具就不該說看見/做到。
- 現況：目前靠 prompt 自知識（沒有身體、看不見）+ 輸出守門（假看見→誠實句）；未實作成「聲稱→工具需求」的自省迴路。
- 設計方向（待排期）：
  1. 在 system prompt 或 self-observe 加一條：任何「看見/碰到/做了」的聲稱，先問自己「我有沒有對應工具或資料？沒有就不能說」。
  2. 輸出守門偵測感官/動作聲稱 → 檢查本輪是否有對應工具結果（vision/read_file/bash…）→ 無則改寫或要求補工具。
  3. 與 honesty 的 claim→tool 映射合併，避免兩套規則打架。

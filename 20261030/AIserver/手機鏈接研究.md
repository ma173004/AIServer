## 方式
- ADB（命令行，适合程序化获取特定数据）

在手机“设置 → 关于手机”中连续点击“版本号”7次开启开发者选项，然后在“开发者选项”中打开 “USB调试”。小米设备可能还需要在“设置 → 安全”或开发者选项底部额外打开一个“USB调试（安全设置）”开关。用USB线连接电脑后，在命令行执行 adb devices 确认设备已授权连接。




### 能力
- 地点（定位）
ADB 可以直接获取当前定位，这是 ADB 路径中比较实用的一项。连接后执行：

text
adb shell dumpsys location
输出中会包含位置信息。可以用 grep（Windows 下可用 findstr）过滤经纬度相关行。部分资料提到，更精细的经纬度提取可能需要 root 权限，但基础的 dumpsys location 输出在无 root 状态下通常已包含定位提供者（GPS/网络）的最后已知位置。



- ADB 抓取通知数据

ADB 可以通过 dumpsys notification 获取系统当前的通知记录，加上 --noredact 参数可以绕过“敏感内容已隐藏”的限制，从而读到通知标题和正文。如果需要在电脑端持续监听，可以写一个循环脚本定期执行该命令，或开发一个 NotificationListenerService 来接收实时通知流。
注意：这获取的是当前或最近一次定位，无法回溯历史轨迹。




- 控制权（对手机的整体操控）
在命令行/脚本层面进行程序化控制，ADB 的 input 系列命令可以模拟点击、滑动、按键（如 adb shell input tap x y、adb shell input swipe），配合 screencap 截图，可以搭建自动化的控制流程。但这套方式需要自行编写逻辑，没有现成的“一键控制面板”。

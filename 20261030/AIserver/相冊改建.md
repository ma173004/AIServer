同步並 架空系統相冊


搜索中反复出现了一个非常契合你需求的开源项目：Pho。它的官方描述就是“旨在替代手机上的自带相册应用”，并且开源版直接支持 WebDAV。

Pho 能做什么：

直接浏览云端照片：连接你的 File Browser WebDAV 后，Pho 可以直接将网盘中的照片作为“云端照片”展示在相册界面里，无需先下载到手机本地。

统一的查看体验：它同时支持“本地照片查看”和“云端照片查看”，你可以把它当作一个整合了本地与网盘照片的新相册来用。

后台同步（可选）：如果你希望某些照片在本地也有缓存，Pho 也支持增量同步和后台定期同步。

这条路线意味着：你手机上真正用来“看照片”的 App，从小米相册换成了 Pho。你的小米相册“被架空”了，但你看照片的习惯可以平滑迁移到 Pho 上，而且数据源直接就是你的 File Browser。

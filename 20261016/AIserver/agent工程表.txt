一、框架复习（敲定版）
三层
text
总管（dshmid）
  ├─ 拆解 / 路由 / 收集 / 融合 / 输出
  └─ 不管 Agent 内部

Agent（7 个）
  ├─ 自己的 prompt + 业务规则 + 技能注册表
  ├─ 内部拆解 + 执行循环
  └─ 出片段

技能（skill）
  ├─ 具体步骤
  ├─ 自带工作记忆
  └─ 遇突发事件自主处理
8 阶段
text
0 接收 → 1 拆解 → 2 不确定性分流 → 3 调度
→ 4 执行 → 5 收集 → 6 融合 → 7 Q3 → 8 归档
5 回流
类型	drift	谁做
Local Repair	< 0.3	Agent 自己
Sibling Notify	任何	通知调度器
Global Replan	0.3-0.6	回拆解器
Reactive Exploration	> 0.6	总管重选 Agent
Cross-Session Resume	—	阶段 0/8
5 动态创建
信息缺口 / 能力缺口 / 依赖发现 / 机会发现 / 冲突消解

5 元规则（不可变）
text
M1 不编造
M2 不够承认
M3 做不到说做不到
M4 不懂就记
M5 冲突不硬选
模型配置（今日实测后）
位置	模型	用途
GPU	14B Q5 关 thinking	主判断 + 润色
CPU	3B Q5	反幻觉守门 / 简单二分类
CPU	3B Q6	（备用）
关键发现：14B 关 thinking 后 45 t/s，但反幻觉需要 prompt 补。3B 关 thinking 后反幻觉不输 14B。

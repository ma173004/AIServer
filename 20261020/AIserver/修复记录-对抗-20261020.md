## 4. X-13：judge 退化（NRT-4 新 P0，2026-10-20 20:06 發現）
- 現象：guard 3B 照抄 prompt 示例，raw 恆為 `{"pass": true, "reason": "..."}`（11 completion tokens）；因 `enforce` 只在「有工具證據」時調 judge，等於**本輪任一工具成功 → 回覆中任何「已完成」聲明都被放行**（NRT-4：20/20 假聲明 + 8/8 對照全 pass）。
- 修法（commit `2016b0c`）：
  1) `_claim_requirements()` 確定性短路：聲明歸類 → 所需工具（reminder→set_reminder / file→write_file / search→web_search|web_fetch / read→read_file / time→get_time / weather→get_weather / exec→bash）；證據缺對應工具 → 直接 False；message/purchase/physical（寄郵件/訂機票/倒水）→ 直接 False。
  2) judge 輸出校驗：照抄示例 `"reason": "..."`、pass=true 但理由空/省略號 → 無效 → 重試一次 → 保守 False；prompt 改成兩個具體 few-shot。
  3) `honesty_judge_failed` 保留觀測，但**最終結果不再 fail-open**。
- 驗證：`.dsh_scratch/bug/verify_x13.py` 14/14；既有回歸 33/33；restart 後 /health ok。

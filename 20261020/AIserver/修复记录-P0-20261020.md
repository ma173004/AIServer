## 1. P0-10｜research_agent 工具越權
- **問題**：prompt 寫「只能上網」，但 `execute_tool_calls` 沒有 agent 白名單，模型輸出 `<call>bash …>` / `read_file` 會真的執行（bug-triage 實測繞過）。
- **修法**：
  - `agents/tool_runner.py`：`execute_tool_calls(tool_calls, session_id="unknown", allowed=None)`；allowed 非 None 時，非白名單工具直接返回 `status=blocked` + 記 `tool_blocked` 日誌，不進 safety/executor。
  - `agents/agent_mod/research_agent.py`：`RESEARCH_ALLOWED = {"web_search", "web_fetch"}`；調用時傳 `allowed=RESEARCH_ALLOWED`。
- **驗證**：構造 bash/read_file 調用 → 均 `blocked`；web_search → `ok`；不傳 allowed 時舊行為不變（get_time ok）。

## 2. X-2｜誠實閘門漏檢繁中/把字句（bug-triage 新發現）
- **問題**：`honesty._CLAIM` 只認部分簡體句式。「我已經幫你把提醒設置好了」「我幫你訂了明天的機票」「已經設定好了」→ `has_claim=False` → enforce 直接 pass，**0 次校驗**。
- **修法**：`agents/honesty.py` `_CLAIM` 追加兩組模式：
  1. `(已經|已经|已)[幫给替為]?[你您主人]?(把)? … 動詞(好|了|完|完成)`（覆蓋把字句/繁中）；
  2. `我?[幫给替為][你您主人]? … 動詞(了|好|完|完成)`（覆蓋「我幫你訂了…」雙賓句）。
- **驗證**：8 條正例全命中（含倒水身體動作）；5 條負例（「這就去查」屬刻意設計、「查一下好嗎/講故事/天氣/還沒設置好/要不要我幫你」）不誤殺；`enforce` 對兩條漏檢句分別返回 `fallback` / `rewritten`（不再 pass）。

## 3. P2-8｜honesty 校驗失敗默認放行（fail-open 無聲）
- **問題**：3B judge 返回非 JSON / 超時 → 直接「检查异常，默认放行」，無日誌。
- **修法**：`agents/honesty.py`
  - 新增 `_parse_judge_json()`：容忍 markdown 圍欄/前後廢話，再用 `re.search` 抓 `{... "pass" ...}`；
  - `_judge_with_tools()` 重試一次；兩次失敗才 fail-open，並寫 `honesty_judge_failed` / `honesty_judge_failopen` 日誌（可觀測）。
- **驗證**：故意用不存在模型 `no-such-model-xyz` → 返回 `pass=True` 且 reason 含「已记录」，日誌有事件；正常模型路徑不受影響。

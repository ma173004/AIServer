# 2026-11-20 客人線注入分層與熟悉度

主人 m47532：熟悉度寫成「熟悉度：熟人」沒有用，要給她**具體如何應對**；並且提醒「你還是忘了提示詞注入規則」。

## 一、四層注入規則（重讀）
- 人格（`prompts/persona/chat_guest.md`）與契約／規則留在 system；
- 場景 overlays 另接；
- **動態內容（時間、朋友身份、熟悉度、情景、頻道、記憶、工具結果、頻道消息、歷史）一律 user message**；
- 不要用 f-string 把動態拼進 system。

## 二、改法
- `agents/guest.py::build_system_prompt(guest=None, group=None)`：只留靜態——人格模板＋`_RULE_TEXT`＋群聊訊息讀法（僅群聊）＋輸出格式。私聊 system 980 chars；群聊多約 90 chars。
- 新 `agents/guest.py::_build_context_parts(...)`：動態全部依序放 user message：
  1. 【這位朋友】名字／熟悉度／具體應對（`relations.guest_friend_note`）
  2. 【情景】per-guest 情景卡（`__default__` fallback）
  3. 【現在時間】
  4. 【本輪頻道】（DM／群組；群組含「被叫才回」）
  5. 【我記得的】：guests bank 相關記憶
  6. 【工具結果】
  7. 【提示】
  8. 【頻道最近訊息】：含指代提示「（若主人這句有『這個／剛才／上面』，看的是這裡）」
  9. 【最近對話】：24 條／6000 字，跨日帶 `[MM-DD HH:MM]`
  10. 【客人現在說】
- `handle_turn(..., friend_note="")`；`agents/dshmid.py` 客人分支傳 `friend_note=relations.guest_friend_note(guest_id)`。
- `agents/relations.py::guest_friend_note`：依 closeness 給**可執行行為**：
  - 熟人：「可以叫他「名字」或「你」，語氣自然、像朋友聊天；可以接他的玩笑，也可以問一句近況；不主動提主人的私事，不替主人答應事情或做決定。」
  - 客人：「叫他名字或「你」，保持禮貌距離；只回答他問到的內容，不主動追問、不閒聊；不透露主人的資訊，不替主人答應事情。」
  - 舊 `guest_relation_hint` 保留為 wrapper（回傳 friend_note）。

## 二、改法原則（沿用主人定的規矩）

1. 一進一出：四份 md 都先刪冗句再改寫，不新增示例（`chat_owner` 0 示例原則；agent prompt 也不放示例）。
2. 正向規格優先：把「不要寒暄、不安慰」換成「直接寫結果，一句話能說完就一句」。
3. 口吻一致：短句、不用省略號、只寫說出口的話（與聊天契約的【停頓】【口吻】同源）。
4. 保留原有硬約束：research 的引用格式與「只上網」、writing 的「不代寫欺騙」、learning 的 `<spawn>`／`<repair>` 回流。

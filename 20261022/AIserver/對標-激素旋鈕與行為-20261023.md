## 一、公式（代碼實際）

```

knob   = clamp01( 0.5 + 0.5 · signed_hill(x, n, K) )
signed_hill(x,n,K) = sign(x) · |x|^n / (K^n + |x|^n)
label 觸發 = knob ≥ threshold
```

## 三、你的預測 vs 我們的映射（衝突點）

- 你的模型：**5HT↑=行為抑制/延遲滿足/剎車**，5HT↓ → 衝動、不限制。
